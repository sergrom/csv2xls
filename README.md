# csv2xls

A command-line tool for converting CSV files to binary Excel XLS workbooks.

XLS output is generated by [xls-writer](https://github.com/sergrom/xls-writer).
This project handles CSV parsing and command-line options.

## Installation

Install [Go](https://go.dev/doc/install) 1.20 or later, then run:

```sh
go install github.com/sergrom/csv2xls/v3@v3.1.0
```

## Usage

Convert a CSV file using the default semicolon delimiter:

```sh
csv2xls --csv-file-name="file.csv" --xls-file-name="file.xls"
```

Show all available options:

```sh
csv2xls --help
```

## Options

| Flag | Description | Default |
| --- | --- | --- |
| `--csv-file-name` | Input CSV file (required). | — |
| `--xls-file-name` | Output XLS file (required). An existing file is overwritten. | — |
| `--csv-delimiter` | Field delimiter: a single character. | `;` |
| `--title` | Document title. | Empty |
| `--subject` | Document subject. | Empty |
| `--creator` | Document creator. | Empty |
| `--keywords` | Document keywords. | Empty |
| `--description` | Document description. | Empty |
| `--last-modified-by` | Name of the last person to modify the document. | Empty |

## Example

Save the following comma-separated data as `cities.csv`:

```csv
ID,City,Country
1,Paris,France
2,Berlin,Germany
3,Madrid,Spain
```

Convert it to XLS with a document title:

```sh
csv2xls --csv-file-name="cities.csv" --xls-file-name="cities.xls" --csv-delimiter="," --title="European cities"
```

The resulting `cities.xls` contains a sheet named `worksheet`:

| ID | City | Country |
| --- | --- | --- |
| 1 | Paris | France |
| 2 | Berlin | Germany |
| 3 | Madrid | Spain |

## Conversion behavior

- Input text must be UTF-8. An initial UTF-8 BOM is removed before parsing;
  embedded BOM characters are preserved.
- All values are written as text: leading zeros are preserved, and values such
  as `=1+1` remain text rather than becoming formulas.
- Records may have different numbers of fields. Permissive quote parsing is enabled.
- Records are split into sheets of 65,535 rows named `worksheet`, `worksheet1`, etc.
- Empty CSV input produces one empty worksheet.
- XLS limits are enforced by xls-writer. Invalid input and file errors are reported
  as conversion errors.
- The workbook is built in memory before it is saved.

## Development

Run the Go checks:

```sh
go build ./...
go test -race ./...
go vet ./...
```

Integration tests read generated workbooks with the independent `xlrd` reader
and check cell values, types, sheet names, row boundaries, and BOM handling:

```sh
python3 -m venv .venv
.venv/bin/pip install -r tests/requirements.txt
.venv/bin/python -m unittest discover -s tests -v
```

The integration suite builds the CLI in a temporary directory. Python and
`xlrd` are test-only dependencies; the converter does not require them.
